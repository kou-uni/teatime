# 誰に、何を出すか（叩き台 2026-10-30）

**いま teatime は7つ出している**（pitch / product / project / feedback の4文書、
プロトタイプ、1枚HTML、解説動画）。これは**機能の棚卸しであって、設計ではない。**
作った側の努力は見えるが、受け取る側の手数は1つも減っていない。

この文書は「足すもの」ではなく「**どれを本体にして、どれを下げるか**」を決めるためのもの。

---

## 1. 欧米の投資家 / スタートアップの文脈

### ペルソナ A — Seed VC のアソシエイト（SF・29歳）
- 週に40本のデッキを見る。**初回は90秒。** iPhone で、会議と会議の間に見る
- 彼が探しているのは事業の説明ではない。**「この創業者と話す理由」**
- **生成された文書は読まない。** AI が書いた資料は、彼の受信箱でいちばん安い物体

**teatime が彼に出せて、他が出せないもの:** 採択ではなく**放棄**。
「何を決めたか」は誰でも言える。「**何を、何のために捨てたか**」は判断の証拠になる。
VC の言葉では **founder judgment** と **decision velocity**。ここは代替品が無い。

### ペルソナ B — 元創業者のエンジェル / オペレーティングパートナー
- 聞きたいのは1つ。**「このチームは学習しているか」**
- 彼が見たいのは現在地ではなく**差分**。先月と今月で、何の順位が入れ替わったか

**teatime が出せるもの:** ⑦**序列の反転ログ**。日付つきで、何が何の上に来たか。
**これは後から作れない。** 捏造するには過去の議論が要る。
いま teatime にこの出力は無い（データは取れている）。**作るならここ。**

### 形（この2人に効く形）

| 出すもの | 中身 | なぜ |
|---|---|---|
| **Decision Memo（英語1枚）** | Decision / What we traded away / What would change our mind / What we don't know yet | 米国の実務者が実際に読んでいる型。4文書を1枚に畳む |
| **反転ログ（時系列1枚）** | 日付・入れ替わった2つの価値・きっかけ | 学習率の証拠。**唯一、時間が経つほど強くなる出力** |
| **60〜90秒の動画** | 冒頭8秒を「何を捨てたか」に使う | 2分16秒は長い。90秒を超えると初回では見られない |

**"What would change our mind" を必ず入れる。** 反証条件を書いた資料は、
それだけで生成物の山から抜ける。Tan の区別がそのまま効く——
**「調べれば出ること」と「決めるしかないこと」を分けて書く。**

### 捨てる案
- **pitch / product / project / feedback の4本立てを英語でも維持する案。** これは稟議の形で、
  投資家の読み方ではない。向こうは1枚と、触れるものしか見ない
- **AI が作ったと分かる見た目を隠す案。** 隠すほど安く見える。
  むしろ「**議論の録音だけから作った。議論に無いことは未入力と書いてある**」を前に出す。
  空欄が残っている資料は、作文していない証拠になる

## 2. 実際に使う側

### ペルソナ C — 議論の主催者（戻ってくる人）
工事会社の役員・60歳・決裁権あり。AI を使い始めているが作ってはいない。
**痛みは「速さ」ではなく「始まらないこと」**（既存の決定。`decisions/taiwa-track-a-and-persona`）。

- 戻ってきた彼が欲しいのは**読み物ではない。品評する対象1つ**
- 4文書を渡すと、**彼の手数が増える。** teatime の設計意図と逆
- 彼が「おっ」と思う瞬間は1つだけ: **自分が言ったのに、言葉にしていなかったことが出てくるとき**

→ 出すのは **1行 ＋ 触れるプロトタイプ**。文書は「開けば見られる」場所に下げる。

### ペルソナ D — その場にいなかった人（**本当の配布先**）
部下、他部署、翌週に合流する人。
- 議事録は読まれない。**「Aでいく。◯◯を取るので、△△はやらない」1行は読まれる**
- 彼が欲しいのは**許可を待たずに動ける根拠**。Tan の言う自律と連携そのもの

→ 出すのは**転送できる単位**。Slack や LINE に貼れて、何も開かずに意味が通るもの。
**いま teatime にこの単位が無い。** 出しているのは全部「ファイル」で、転送できない。

### 「欲しくなる」の正体
便利さでは欲しくならない。**自分について知らなかったことが出てくると欲しくなる。**
- ×「議事録ができました」
- ○「**今日、理由を言わずに4つ落としています。そのうち2つは先月も落としています**」

これは ⑥⑦ が貯まらないと出せない。**だから蓄積が製品で、文書は副産物。**

## 3. 結論（決めてほしいこと）

**足さない。入れ替える。**

| | いま | 案 |
|---|---|---|
| 本体 | 4文書 | **1行（トレードオフ）＋ プロトタイプ** |
| 投資家向け | pitch.md（日本語） | **Decision Memo（英語1枚）** |
| 時間とともに強くなるもの | 無い | **反転ログ** ←新規。ここだけ作る |
| 動画 | 2分16秒 | **60〜90秒**。冒頭8秒は放棄 |
| 4文書 | 前面 | 下げる（開けば見られる） |

### 作る前に塞ぐ穴
**いまの成果物は tailnet にしか無い。** 投資家もペルソナDも開けない。
**誰でもアカウント無しで開く URL が無い限り、上のどれも届かない。**
